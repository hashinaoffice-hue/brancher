# Instagram

## 계정의 역할

브랜처 계정 = **빌드 인 퍼블릭 채널.** 무엇을, 왜, 어떻게 만들었고, 숫자가 어떻게 나왔는지 보여준다.
제품 사용자 대상 홍보는 각 제품 계정이 맡는다. (1순위 청중 결정에 따라 수정)

## 프로필

**이름:** `brancher | 브랜처`

**소개**
```
Venture Studio
Branch out. Build ventures.
branch 01 ▸ 핸드머니
Business inquiry: DM
```

- 원본 그대로 유지. 짧고 단정함.
- 브랜치가 늘면 3행을 최신 브랜치로 교체하거나 `branch 01–02 ▸ 링크`로 압축.
- 프로필 사진: `brand/logo/exports/brancher-instagram-profile-1080.png` (블랙 배경, 화이트 줄기, 그린 스퀘어)

## 첫 피드 캡션 (수정안)

```
brancher.
Branch out. Build ventures.

모든 프로젝트는 하나의 브랜치에서 시작합니다.
분야를 가리지 않고 시도하고, 빠르게 만들고, 검증된 것만 키웁니다.

branch 01 ▸ 핸드머니
계획하고, 기록하고, 검토하는 자산관리 앱입니다.

#brancher #브랜처 #벤처스튜디오 #핸드머니 #스타트업
```

원본 대비 변경점:
1. 2문단을 세 원칙(Branch out / Ship fast / Merge what works)과 1:1로 맞춤 — "분야를 가리지 않고 / 빠르게 만들고 / 검증된 것만 키웁니다"
2. `branch 01 — 핸드머니.` → `branch 01 ▸ 핸드머니` (표기 통일)
3. `#사이드프로젝트` 제거 — 벤처 스튜디오 포지셔닝과 충돌

## 콘텐츠 기둥

| 기둥 | 내용 | 비중 |
|---|---|---|
| **Branch log** | 새 브랜치 오픈, 출시, merge/close 발표 | 30% |
| **Numbers** | 브랜치별 숫자 업데이트. 좋든 나쁘든 | 30% |
| **Build notes** | 만드는 과정, 결정, 실패, 도구 | 30% |
| **Brand** | 이름·로고·원칙 이야기 | 10% |

## 첫 9개 그리드 (3×3)

인스타그램은 최신 글이 왼쪽 위에 오므로, **아래 순서대로 올리면** 그리드가 완성됩니다.

| 순서 | 기둥 | 내용 |
|---|---|---|
| 1 | Brand | 브랜드 소개 — 블랙 배경, 로고, `Branch out. Build ventures.` |
| 2 | Brand | 로고 해부 — 줄기 / 45° 가지 / 그린 스퀘어. 그리고 워드마크의 스퀘어 = 마침표 `brancher.` |
| 3 | Brand | 세 원칙 (캐러셀 3장) |
| 4 | Branch log | `branch 01 ▸ 핸드머니` 오픈 |
| 5 | Build notes | 핸드머니가 푸는 문제 — 왜 '계획·기록·검토'인가 |
| 6 | Build notes | 만든 방법 — 기간, 도구, 인원을 숫자로 |
| 7 | Brand | 이름 이야기 — Branch + -er, 그리고 숨은 '벤처' |
| 8 | Numbers | 핸드머니 첫 숫자 |
| 9 | Branch log | `branch 02` 티저 — "준비 중" |

## 포맷

- 피드 이미지: **1080 × 1350 (4:5)**. 그리드 썸네일이 3:4로 잘리므로 좌우 끝에 핵심 요소를 두지 않는다.
- 배경은 블랙 기본, 화이트는 대비가 필요할 때만.
- 캡션 첫 줄은 커밋 메시지처럼 — `branch 01 ▸ v0.3 출시` 같은 사실 한 줄.
