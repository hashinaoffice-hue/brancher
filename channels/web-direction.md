# Web 연출·기능 설계 — 시안 v2 기획

> 2026.11.25. [시안 v1](https://claude.ai/artifact/FBwWKj9Jxavz52zkwMe2t5)을 진단하고, v2에서 바꾸고 더할 것을 정한다. 승인되면 시안에 반영한다.
> 기준: [`web.md`](web.md) · [`../brand/brand-book.md`](../brand/brand-book.md)

## 1. 시안 v1 진단

| 잘 된 것 — 지킨다 | 부족한 것 — 고친다 |
|---|---|
| 브랜드 규칙을 지켰다: 블랙 무대, 그린은 결과물에만, 대각 라운드 | **첫 화면에 움직임이 없다.** 로고 이야기(가지 → 결과물 → 마침표)가 정지 화면이다 |
| 휴대폰 한 줄 구성. 인스타에서 바로 읽힌다 | **모든 블록의 무게가 같다.** 웹페이지가 아니라 문서처럼 읽힌다 |
| '지금'과 '출시 후' 두 시점을 모두 설계했다 | **Git 은유가 화면 구조에 없다.** 문구에만 있다 |
| 관리자 숫자를 merge 기준 옆에 두었다 | **공유 미리보기가 없다.** 인스타 DM·카톡으로 링크가 돌 때 빈 카드가 뜬다 |
| | **관리자에 문장이 없다.** 숫자를 읽고 해석하는 일이 전부 내 몫이다 |
| | **알림이 없다.** 문의를 보려면 앱을 직접 열어야 한다 |
| | **ship · merge · close가 한 번 누르면 끝이다.** 지울 수 없는 기록인데 확인과 메모가 없다 |

## 2. 연출 콘셉트 — 한 줄기가 페이지를 관통한다

페이지 전체가 하나의 Git 그래프다.

- 첫 화면의 워드마크 아래에서 **줄기(main)** 가 시작해 페이지 끝까지 내려간다. 스크롤하면 줄기가 자란다.
- 각 섹션은 줄기 위의 커밋 점이다.
- 만든 것은 줄기에서 **45°로 뻗은 가지** 끝에 달린다. 출시된 가지 끝에는 그린 스퀘어가 놓인다.
- 줄기는 바닥에서 심볼의 줄기로 이어지며 끝난다.

> 대담함은 이 줄기 한 곳에만 쓴다. 나머지는 조용하게 둔다.

## 3. 모션 원칙 — 동사는 셋뿐

브랜처의 원칙 세 개가 곧 모션의 문법이다. 새 움직임을 넣을 때는 이 셋 중 어디에 속하는지 먼저 본다. 셋에 없으면 넣지 않는다.

| 동사 | 원칙 | 움직임 | 쓰는 곳 |
|---|---|---|---|
| **뻗는다** | Branch out | 선이 0에서 끝까지 그려진다. 수직 또는 45°로만 | 줄기, 가지 연결선, 차트 선 |
| **내놓는다** | Ship fast | 그린 스퀘어가 제자리에 놓인다. 짧고 단호하게, 튕기지 않게 | 워드마크 마침표, 출시 카드, 문의 보냄, 기준 달성 |
| **키운다** | Merge what works | 막대와 숫자가 차오른다 | 관리자 숫자, merge 기준 막대 |

**규칙**
- 방향은 0° · 90° · 45°만. 회전, 흔들림, 튕김(bounce), 블러, 패럴랙스는 쓰지 않는다.
- 가속 곡선은 하나만 쓴다: `cubic-bezier(0.2, 0, 0, 1)`. 빠르게 출발해서 단정하게 멈춘다.
- 시간은 세 단계: 피드백 150ms · 요소 400ms · 시그니처 1,200ms(한 번).
- **그린 스퀘어는 '내놓는다' 순간에만 움직인다.** 그린이 결과물이니, 그린의 움직임도 결과가 나오는 순간뿐이다.
- 읽기를 막지 않는다. 글은 처음부터 보인다. 모션은 선, 스퀘어, 숫자에만 쓴다. 로딩 화면은 없다.
- 한 번만 움직인다. 시그니처는 방문당 한 번, 스크롤 등장도 한 번.
- 기기에서 '동작 줄이기'를 켠 사람에게는 모션을 모두 끄고 완성된 화면을 보여준다.

## 4. 공개 페이지 v2 — 장면별

| 장면 | 화면 | 모션 |
|---|---|---|
| **1. 첫 화면** | 워드마크 · 가지를 뻗는 사람 · 태도 문장 | **시그니처 (1.2초).** `brancher` 글자가 왼쪽에서 오른쪽으로 드러난다(뻗는다). 마지막에 그린 마침표가 위에서 내려와 놓인다(내놓는다). 이어서 워드마크 아래에서 줄기가 자라기 시작한다 |
| **2. 줄기** | 왼쪽 2px 선. 섹션 제목마다 커밋 점 | 스크롤한 만큼 줄기가 자란다. 지나간 커밋 점이 채워진다 |
| **3. 만든 것** | 줄기에서 45°로 뻗은 가지 끝에 카드 | 카드가 화면에 들어오면 가지 선이 뻗고(400ms), 출시된 가지는 끝에 그린 스퀘어가 놓인다. 만드는 중인 가지는 점선과 빈 스퀘어 |
| **4. 방식** | 도식 자체가 Git 그래프: 갈라짐 → 결과물 → 합침 | 스크롤에 맞춰 한 단계씩: 가지가 갈라지고(뻗는다) → 끝에 스퀘어가 놓이고(내놓는다) → 줄기로 다시 합쳐진다(키운다) |
| **5. 문의** | 메일 주소 · 양식 | 보내기를 누르면 버튼이 줄어들어 그린 스퀘어가 되어 놓인다 → `받았습니다. 메일로 답장합니다.` |
| **6. 바닥** | Branch out. Build ventures. · 심볼 | 줄기가 내려와 심볼의 줄기와 이어진다 (정지 상태로 끝) |

- 카드나 버튼에 마우스를 올리거나 누르면 테두리만 밝아진다(150ms). 크기는 바뀌지 않는다.
- 데스크톱은 같은 구조를 더 넓게 쓴다. 왼쪽에 줄기, 가운데에 내용. 다른 레이아웃을 따로 만들지 않는다.

## 5. 추가 기능 — 공개 페이지

| 기능 | 왜 | 단계 |
|---|---|---|
| **가지 상세 시트** (`brancher.kr/branch/01`) | 동료 개발자에게 보여줄 깊이: 무엇 · 왜 · 기술 · 기간 · 상태 · 가지 기록. 따로 공유할 수 있는 주소 | 시안 v2 |
| **공유 미리보기 이미지** | DM·카톡으로 링크가 돌 때 첫인상. 사이트용 1장 + 가지마다 1장, 1200 × 630, 블랙 바탕 + 워드마크 또는 `branch 01 ▸ 이름` | 운영 v0 |
| **인스타 앱 안 브라우저 대응** | 방문자 대부분이 인스타 앱 안에서 연다. 첫 화면 1.5초 안, 스크립트 30KB 이하, 라이브러리 없이 구현, 서체는 필요한 글자만 | 운영 v0 |
| **검색 정보** | 제목·설명·사이트 정보. "브랜처"를 검색하면 나오게 | 운영 v0 |
| **최근 기록** *(Q12)* | 브랜처가 살아 있다는 신호. 커밋 로그 형식 5줄 | 결정 후 |
| **답장 기간 안내** *(Q13)* | `보통 N일 안에 답장합니다.` 지킬 수 있는 숫자일 때만 | 결정 후 |

- **화면은 다크 하나만 둔다** *(Q14)*. 라이트 모드를 만들지 않는다. 블랙이 브랜드의 무대이고, 흰 배경 위의 그린은 글자로 읽히지 않는다(2.45 : 1).

## 6. 추가 기능 — 관리자 모드

| 기능 | 왜 | 단계 |
|---|---|---|
| **요약 문장** | main 맨 위에 한 문장: `이번 주 방문 412명. 지난주보다 18% 늘었습니다. 새 문의 2건.` 숫자를 해석하는 시간을 줄인다 | 시안 v2 |
| **ship · merge · close 확인 단계** | 날짜와 메모를 입력한 뒤 확정한다. close는 회고 3줄이 필수 ([`branches/README.md`](../branches/README.md) 회고 칸) | 시안 v2 |
| **기간 선택** | 7 · 30 · 90일, 이전 기간과 비교 | 시안 v2 |
| **새 문의 알림** | 문의가 오면 바로 휴대폰 알림. 아이폰은 홈 화면에 설치한 앱에서만 받는다 (iOS 16.4 이상) | 운영 v1 |
| **Gmail에서 답장** | 메일 앱으로 바로 열고, 상태는 자동으로 '답장함'. 답장까지 걸린 시간이 기록된다 | 운영 v1 |
| **차트 메모** | 인스타 게시물·업데이트 날짜를 차트 위에 점으로 표시한다. 어떤 게시물이 사람을 데려왔는지 보인다. 게시물 링크의 `utm_campaign`으로 자동 연결 | 운영 v2 |
| **경보** | merge 기한 7일 전, 오류 비율 급증, 방문이 평소의 2배 | 운영 v2 |
| **주간 리포트** | 월요일 아침 알림 1건. 마크다운으로 내보내 `branches/`의 숫자 로그에 붙인다 | 운영 v2 |
| **가지 등록·편집** | 한 번 입력하면 공개 카드와 상세 시트에 함께 쓰인다 | 운영 v2 |

**관리자 모션** — 같은 세 동사만 쓴다.
- 탭 전환: 150ms 교차 전환
- 숫자: 첫 로드에 한 번 차오른다(400ms). 고정폭 숫자라 자리가 흔들리지 않는다
- 차트 선: 왼쪽에서 오른쪽으로 그려진다
- merge 기준을 넘는 순간: 막대 끝 스퀘어가 그린으로 놓인다

## 7. 하지 않을 것 — 연출이 허세가 되는 지점

| 하지 않는다 | 이유 |
|---|---|
| 로딩 화면, 인트로 영상 | 인스타에서 온 사람은 기다리지 않는다 |
| 스크롤 가로채기, 패럴랙스, 커서를 따라다니는 효과 | 읽기를 방해한다. 보이스의 '단정하게'와 반대 |
| 3D, 파티클, WebGL 배경 | 무겁고, 브랜드 형태(직선과 45°)에 없다 |
| 타자기 효과, 끝없이 흐르는 글자띠 | 흔한 장식. 브랜처만의 것이 아니다 |
| 튕김, 그림자, 그라데이션, 빛 번짐 | 브랜드북 Form에서 금지 |
| 공개 페이지 숫자 카운트업 | 공개 숫자를 쓰지 않기로 했다 (2026.11.25) |
