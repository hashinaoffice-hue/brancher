## 2. 제안 — 세 동사를 장면에 하나씩 나눠 싣는다

지금은 S3 한 장면에 세 동사를 목록으로 몰아 두고, 뒤에서 하나를 다시 꺼낸다. 대신 **동사를 그 일이 실제로 일어나는 장면에 하나씩** 둔다. 화면이 동사를 직접 보여주므로 설명이 짧아진다.

| 장면 | 화면에서 일어나는 일 | 동사 |
|---|---|---|
| S3 가지 | 줄기에서 가지가 자란다 | **뻗는다** |
| S4 마침표 | 그린 스퀘어가 가운데 찍힌다 | **내놓는다** |
| S5 만든 것 | 가지들이 상태별로 놓여 있다 (만드는 중 · 출시 · 키우는 중) | **키운다** |

이렇게 하면 A(반복)와 B(역행)가 함께 풀린다. 각 동사는 한 번씩만 나오고, 순서도 뻗는다 → 내놓는다 → 키운다로 앞으로만 간다.

## 3. 장면별 제안 문구

`굵게` = 제안. 다른 안이 있는 곳은 *안 2*로 적었다.

### S0 서명
| 요소 | 지금 | 제안 |
|---|---|---|
| 위 줄 | 1인 개발 브랜드 | **1인 개발 브랜드** (유지) |
| 제목 | 빠르게 만들고, 천천히 키운다. | **빠르게 만들고, 천천히 키운다.** (유지 — 브랜드 태도 문장) |
| 안내 | 스크롤 | **스크롤** (유지) |

### S2 줄기 — 이름의 뜻
| 요소 | 지금 | 제안 |
|---|---|---|
| 위 줄 | 소개 | **brancher** |
| 제목 | 브랜처는 1인 개발 브랜드입니다. | **가지를 뻗는 사람.** |
| 설명 | 직접 만든 서비스를 하나씩 내놓고, 반응이 오는 것을 키웁니다. | **브랜처라는 이름의 뜻입니다.** |
| 숫자 | 운영 1인 · 시작 2026.10 · 가지 1 | 유지 |

- 근거: 브랜드북 Name("Brancher = 가지를 뻗는 사람")을 처음 꺼낸다. 줄기 위에서 이름 이야기를 하고, 다음 장면에서 실제로 가지가 뻗는다.
- '벤처' 발음 이야기는 넣지 않는다. 브랜드북 원칙대로 숨겨 둔다.
- *안 2:* 제목 "혼자, 하나씩." / 설명 "직접 만든 서비스를 하나씩 세상에 내놓습니다."

### S5 만든 것 — 키운다
| 요소 | 지금 | 제안 |
|---|---|---|
| 위 줄 | 만든 것 | **만든 것** (유지) |
| 제목 | 지금까지 뻗은 가지 | **지금까지 뻗은 가지** (유지) |
| 설명 | — | **반응이 온 가지만 키웁니다.** |

- "천천히"는 S0 태도 문장에만 둔다. 여기서 빼서 반복을 피한다.
- 영문 원칙 "Merge what works"는 고객 화면에 넣지 않는다. 고객 글에서 Git 용어를 쓰지 않는다는 규칙 때문이다. 같은 이유로 S3 · S4의 영문도 **빼는 안**을 함께 검토해야 한다 → 질문 2.
