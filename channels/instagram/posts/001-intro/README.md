## 캡션

```
모든 사업은 하나의 가지에서 시작된다.

브랜처는 1인 벤처 스튜디오입니다.
아이디어가 보이면 가지를 뻗고, 빠르게 만들어 시장에 내놓고,
반응이 오는 것을 사업으로 키웁니다. 분야는 정해두지 않습니다.

첫 번째 가지는 핸드머니입니다.
계획하고, 기록하고, 검토하는 자산관리 앱으로, 지금 출시를 준비하고 있습니다.

혼자서 어디까지 뻗을 수 있는지, 이 계정에 기록합니다.

#브랜처 #brancher #1인개발 #1인창업 #인디해커 #핸드머니 #자산관리
```

## 대체 텍스트 (고급 설정 → 대체 텍스트 작성)

1. 검은 배경에 "모든 사업은 하나의 가지에서 시작된다." 문장과 brancher 로고.
2. "브랜처는 1인 벤처 스튜디오입니다." 줄기에서 뻗은 세 가지 끝에 뻗는다, 내놓는다, 키운다가 차례로 적혀 있다.
3. branch 01 핸드머니. 계획하고, 기록하고, 검토하는 자산관리 앱. 출시 준비 중.
4. "혼자서 어디까지 뻗을 수 있는가." 줄기에 branch 01 핸드머니가 달려 있고, 그 위에 branch 02 자리가 점선으로 비어 있다.
