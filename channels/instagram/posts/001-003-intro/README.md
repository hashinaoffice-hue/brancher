## 001 · 선언 — `p001.png`

**이미지:** 모든 사업은 하나의 가지에서 시작된다■ (마침표 = 그린 스퀘어)

## 002 · 정체 — `p002.png`

**이미지:** 워드마크 `brancher.` · 1인 벤처 스튜디오

**캡션**
```
1인 벤처 스튜디오, 브랜처입니다.

#브랜처 #brancher #1인개발 #1인창업 #인디해커
```

**대체 텍스트:** 검은 배경 가운데 brancher 로고와 "1인 벤처 스튜디오" 문구.

## 003 · 방식 — `p003.png`

**이미지:** 줄기에서 뻗은 세 가지 — 뻗는다 (빈 칸) → 내놓는다 (흰색) → 키운다 (그린). 가지 끝 결과물이 자라며 색이 채워진다.

**캡션**
```
뻗고, 내놓고, 키운다.

분야를 가리지 않고 가지를 뻗고,
빠르게 만들어 시장에 내놓고,
반응이 오는 것을 사업으로 키웁니다.

혼자서 어디까지 뻗을 수 있는지, 이곳에 기록합니다.

#브랜처 #brancher #1인개발 #1인창업 #인디해커
```

**대체 텍스트:** 줄기에서 뻗은 세 가지 끝에 아래부터 뻗는다, 내놓는다, 키운다가 적혀 있고, 맨 위 키운다의 사각형만 초록색이다.
