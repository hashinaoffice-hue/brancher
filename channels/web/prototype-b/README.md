## A안과 다른 점

| # | 무엇 | A안 (v4.12) | B안 (v4.14) |
|---|---|---|---|
| 1 | 그린 진입 · 퇴장 | 카메라가 스퀘어 안으로 확대. 중간에 양옆 블랙 띠(레터박스), 퇴장 땐 각진 직사각형 | 스퀘어가 대각 라운드를 유지한 채 화면 크기로 열린다. 둥근 두 모서리가 화면 모서리로 마지막에 빠져나간다. 퇴장은 거꾸로 닫혀 스퀘어로 돌아간 뒤 물러남 |
| 2 | 정원 | 여섯 겹 · 블랙 잎 · 흰 꽃 · 바코드 같은 풀. 테두리가 콘텐츠보다 셈 | 세 톤(블랙 9% · 17% · Green Deep), 꽃은 짙은 녹색으로 적게, 풀 듬성. 화면 가장자리에서 가운데로 띠별로 자라 들어오고, 거꾸로 물러난다 |
| 3 | 다이브 | 글자가 투명도로 회색이 되며 사라짐 | 서명의 반대: 글자가 오른쪽에서 왼쪽으로 지워져 b의 줄기만 남는다 (회색 없음) |
| 4 | 길이 | 약 14.6화면 | 약 13화면. 글을 읽는 구간은 줄이고(가지 2.25 → 1.25, 정원 2.85 → 1.35), 전환은 늘림(아래 표) |
| 6 | 화면이 스크롤을 따라오는 방식 | 스크롤 위치 그대로 | 화면이 스크롤을 약 0.35초 늦게 따라온다. 빠르게 넘겨도 전환이 건너뛰어지지 않고 보인다. 스크롤 자체는 브라우저 그대로(가로채지 않음), 동작 줄이기에서는 끔 |
| 5 | 타이포 | 첫 화면 태도 문장 64px Bold, 장면 이름 14px, 숫자 라벨 12px 흐린 회색 | 태도 문장 40px SemiBold(워드마크가 주인공), 장면 이름 15–17px, 숫자 라벨 14px. 흐린 회색 `#6F7773` → `#858D89`(작은 글씨 대비 약 4.1 → 5.5:1) |
| + | 가지 장면 글 | 오른쪽 아래 구석 | PC는 가지가 뻗는 쪽(오른쪽 위) 빈 공간 |
| + | 휴대폰 줄기 | 위아래가 떠 있는 막대 | 화면 위에서 내려오는 벽 |
| + | 그린 위 글 · 입력칸 | 회녹색 본문, 블랙 입력칸 세 덩어리 | 본문은 블랙만. 입력칸 · 메일 칸은 옅은 블랙 면 + 선, 블랙 면은 '보내기'에만 |
| + | 빈 자리 카드 | 2px 블랙 점선 | 1.5px 흐린 점선 |
| + | 마침표 장면 | 스퀘어가 제목 폭의 약 40% | 카메라를 조금 물려 약 33% |
| + | 장면 라벨 | 이름 장면이 '줄기', 그린 퇴장 중 '문의'가 남음 | '이름' 표시, 퇴장이 시작되면 '07 brancher' |
| + | 숫자 줄 | `1 · 만드는 중` | 숫자는 `1`만, 상태는 라벨로 |
| + | 모서리 반경 | 6 · 8 · 10 · 12px | 두 단계: 6px(칩 · 라벨) · 14px(카드 · 입력칸 · 미니맵) |

확인: 크롬 계열 PC 1440 · 휴대폰 390 · 동작 줄이기. 콘솔 오류 없음. 아이폰 사파리 · 인스타 앱 안 브라우저는 A안과 마찬가지로 미확인.
