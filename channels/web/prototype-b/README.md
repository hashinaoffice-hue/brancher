## v4.15 (2026.11.26) — 간격 규칙, 문의 문장

사용자 의견: 문의 장면의 간격이 제각각이다(메일 칸 → 라벨 24px, 입력칸 → 라벨 12px). 간격을 규칙으로 맞춘다.

**간격 단계** — 이 여덟 값 밖의 간격은 쓰지 않는다.

| 토큰 | `--sp1` | `--sp2` | `--sp3` | `--sp4` | `--sp5` | `--sp6` | `--sp7` |
|---|---|---|---|---|---|---|---|
| px | 4 | 8 | 12 | 16 | 24 | 32 | 48 |

**규칙**

| 사이 | 간격 | 예 |
|---|---|---|
| 위 줄(장면 이름) → 제목 | 8 (`sp2`) | 문의 → 만드는 사람이 직접 답합니다. |
| 라벨 → 입력칸 | 8 (`sp2`) | 회신 받을 메일 → 입력칸 |
| 제목 → 본문 | 16 (`sp4`) | 제목 → 설명 문장 |
| 같은 종류 항목 사이 | 24 (`sp5`) | 입력 항목 사이, 메일 칸 → 첫 입력 항목, 카드 사이 |
| 본문 → 항목 · 숫자 묶음 | 32 (`sp6`) | 설명 → 메일 칸, 설명 → 숫자 줄, 설명 → 카드 |
| 단과 단 (PC 2단) | 48 (`sp7`) | 문의 왼쪽 ↔ 양식 |
| 상자 안쪽 여백 | 16 · 24 | 입력칸 좌우 16, 카드 PC 24 · 휴대폰 16 |

- 입력 줄 높이는 하나: `--ctl` 52px (메일 칸, 입력칸, 보내기 버튼).
- 메일 칸에도 라벨 '메일'을 붙여, 문의 장면은 '라벨 + 칸' 묶음이 24 간격으로 반복된다.
- 장면 이름 + 제목은 `.hg` 묶음으로 모든 장면에 같게 적용했다(서명 · 이름 · 줄기 · 가지 · 마침표 · 정원 · 문의 · 끝).

**문의 문장** (결정 대기 Q18)

| | A안 · v4.14까지 | v4.15 |
|---|---|---|
| 제목 | 메일로 연락 주세요. | **만드는 사람이 직접 답합니다.** |
| 설명 | 양식으로 보내셔도 됩니다. (휴대폰에서는 숨김) | 협업 제안도, 작은 아이디어도 좋습니다. 2일 안에 답장합니다. |
| 내용 칸 안내 | 없음 | 예: 이런 서비스가 있으면 좋겠습니다. |
| 보낸 뒤 | 받았습니다. 메일로 답장합니다. | 받았습니다. 2일 안에 메일로 답장합니다. |

- '2일'은 지킬 수 있는 약속이어야 한다. 확정 전 숫자 확인 필요.
