# 브랜드 진단 v1 — 2026.10.26

브랜딩 컨설턴트 관점에서 본 현재 브랜처의 상태. 잘 된 것, 위험한 것, 다음에 할 일.

---

## 1. 잘 된 것 — 지키세요

**하나의 은유로 전부 설명된다.**
이름(branch), 로고(브랜치 구조), 원칙(branch → ship → merge), 프로젝트 번호(`branch 01`)가 전부 Git 하나에서 나옵니다. 신생 브랜드가 이 정도 일관성을 갖는 경우는 드뭅니다. 앞으로 무엇을 추가하든 "이게 Git 은유 안에 들어가는가?"를 기준으로 삼으면 됩니다.

**`branch NN`은 콘텐츠 엔진이다.**
번호가 붙는 순간 프로젝트가 '시리즈'가 됩니다. 사람들은 01을 보면 02를 기다립니다. 브랜드 스토리가 자동으로 이어지는 구조입니다.

**절제된 팔레트.**
블랙·화이트 + 그린 하나. 그린 = 결과물이라는 의미까지 붙어 있어서, 그린을 아무 데나 쓰지 않을 이유가 명확합니다.

## 2. 위험한 것 — 지금 정리하세요

### 2-1. "누구에게 말하는가"가 비어 있다 ⚠️ 가장 중요

벤처 스튜디오 브랜드는 청중이 여럿입니다.

| 청중 | 관심사 | 브랜처를 보는 이유 |
|---|---|---|
| 제품 사용자 | 핸드머니가 쓸 만한가 | 거의 없음. 제품 브랜드를 봄 |
| 파트너·클라이언트 | 같이 일할 만한가 | "Business inquiry: DM" |
| 투자자 | 실행력, 숫자 | 트랙 레코드 |
| 빌더·동료 | 어떻게 만드는가 | 과정, 회고, 숫자 |

지금 문구는 모두에게 조금씩 말하고 있습니다. **1순위 청중**을 정하면 인스타그램 콘텐츠, 바이오, 톤이 자동으로 정해집니다.

→ 제안: 1순위는 **빌더·동료 + 잠재 파트너**. 브랜처 계정은 "빌드 인 퍼블릭(build in public)" 채널로, 제품 사용자는 각 제품 계정이 담당.

### 2-2. "분야 제한 없음"은 강점이자 약점

자유로움은 매력이지만, 외부에서 보면 "그래서 뭘 잘하는데?"가 됩니다.
분야 대신 **방식**으로 정체성을 고정해야 합니다. 브랜처의 공통분모는 분야가 아니라 이것입니다:

> 작게 만들어서, 빨리 내놓고, 숫자로 판단한다.

이미 원칙에 들어 있습니다. 이 방식을 **눈에 보이게 증명**하는 것이 브랜딩의 전부입니다.

### 2-3. "사실과 수치로 말합니다" — 아직 수치가 없다

보이스 원칙이 수치인데, 보여줄 숫자 체계가 없습니다. 브랜치마다 기록할 지표를 미리 정해두세요. (`branches/README.md`에 템플릿 마련)

### 2-4. Merge what works → 그럼 merge 안 된 것은?

원칙상 **닫히는 브랜치가 반드시 생깁니다.** 이걸 숨기면 원칙이 거짓말이 되고, 공개하면 가장 강력한 차별점이 됩니다. 대부분의 스튜디오는 성공만 보여줍니다.

→ 제안: 브랜치 상태를 Git처럼 공개 — `open` → `shipped` → `merged` / `closed`. 닫을 때는 짧은 회고와 숫자를 남김.

### 2-5. "Business inquiry"의 뜻이 모호하다

외주 개발 문의? 공동 창업 제안? 투자? 제휴? 받는 쪽이 정해야 들어오는 문의의 질이 정해집니다. 외주를 받는다면 "벤처 스튜디오"보다 "에이전시"로 읽힐 위험도 있습니다.

### 2-6. 작은 디테일

- **#사이드프로젝트 해시태그 제거 권장.** "벤처 스튜디오"라는 포지셔닝을 스스로 낮춥니다.
- **표기 통일.** 같은 문서 안에서 `branch 01:`, `branch 01 ▸`, `branch 01 —`이 섞여 있음 → `▸`로 통일 (`brand-book.md` 표기 규칙).
- **그린 텍스트 대비.** `#4FB88A`는 흰 배경에서 2.45:1로 텍스트에 부적합. 블랙 배경에선 7.72:1로 아주 좋음. → 그린의 무대는 블랙.
- ~~**인스타 원형 프로필.** 원형 크롭 대응 필요.~~ → 2026.10.26 해결. 원본 심볼이 원형 안에 여유 있게 들어감. 블랙 배경 프로필 이미지 제작 완료.
- **'벤처' 발음 레이어.** 영어 화자에게도, 한국어 화자에게도 첫눈에 들리진 않습니다. 앞에 내세우지 말고 "알고 보니" 이야기로 쓰세요.
