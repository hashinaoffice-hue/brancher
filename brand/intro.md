# 소개 문구 세트

쓰는 곳의 길이에 맞춰 골라 씁니다. 새로 쓰지 말고 여기서 가져갑니다.
`{중괄호}`는 아직 채우지 않은 값입니다.

> 청중: **제품 사용자** (`decisions.md` 2026.10.27). 그래서 Git 용어(merge, close 등)는 소개 문구에 쓰지 않습니다. `branch 01`은 번호 라벨로만 씁니다.

## 한 줄 — 바이오, 명함, 서명

**EN**
> brancher is a one-person venture studio that turns ideas into products, fast.

## 세 줄 — DM 답장, 제안서 첫 장, 앱 정보 화면

**KR**
> 브랜처는 {이름}이 운영하는 1인 벤처 스튜디오입니다.
> 분야를 가리지 않고 시도하고, 빠르게 내놓고, 검증된 것만 키웁니다.
> 첫 번째 결과물은 자산관리 앱 핸드머니입니다.

**EN**
> brancher is a one-person venture studio run by {Name}.
> We try anything, ship fast, and grow only what works.
> Our first product is Handmoney, an app for planning, tracking, and reviewing your assets.

## 소개 페이지 — 웹사이트, 노션

```
brancher.
Branch out. Build ventures.
새로운 가지를 뻗고, 사업으로 키운다.

브랜처는 아이디어를 빠르게 제품으로 만들어 내놓는 1인 벤처 스튜디오입니다.
분야에 제한을 두지 않습니다. 쓸모가 보이는 것이라면 무엇이든 만듭니다.

일하는 방식
1. 분야를 가리지 않고 시도합니다.
2. 빠르게 만들고, 시장에서 확인합니다.
3. 검증된 것만 키웁니다.

만든 것
branch 01 ▸ 핸드머니 — 계획하고, 기록하고, 검토하는 자산관리 앱  {링크}
branch 02 ▸ 준비 중

만든 사람
{이름} — {한 줄 이력}

문의
광고 · 제휴 · 공동 창업 · 기타  {이메일}
```

## 만든 사람 소개

**짧게**
> {이름} — 브랜처 대표. {한 줄 이력}.

**길게** *(세 문장 이내)*
> {이름}은 브랜처를 혼자 운영합니다. {무엇을 해왔는지 — 사실 한 문장}. 핸드머니는 {만든 이유 — 한 문장}.

- 사실만 씁니다. "열정", "혁신" 같은 형용사는 쓰지 않습니다.
- 숫자가 있으면 숫자로. "오래 일했다" 대신 "7년간 {직무}".

## 문의 안내 문구

| 쓰는 곳 | 문구 |
|---|---|
| 인스타 바이오 | `광고·제휴 문의: DM` |
| 웹사이트·노션 | `광고 · 제휴 · 공동 창업 · 기타 문의 — {이메일}` |
| 앱 내 정보 화면 | `made by brancher · {이메일}` |

> 제안: 광고·제휴 문의는 DM보다 **이메일**로 받는 편이 좋습니다. DM은 묻히고, 이메일은 기록이 남아 조건을 주고받기 쉽습니다. 바이오에는 DM, 실제 조건 논의는 이메일로 넘기세요.
