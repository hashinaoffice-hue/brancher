# 소개 문구 세트

짧게. 브랜처만 소개합니다.

- 작업물(핸드머니 등)은 소개에 넣지 않습니다. 각 가지는 공개될 때 따로 소개합니다.
- 운영 사정은 쓰지 않습니다. **1인**은 정체성으로만 말합니다.
- 톤: 진취적으로, 그러나 단정하게 — 브랜드북 [Voice](brand-book.md#voice).

## 뼈대

| 선언 | 정체 | 방식 | 도전 |
|---|---|---|---|
| 모든 사업은 하나의 가지에서 시작된다. | 1인 벤처 스튜디오 | 뻗고, 내놓고, 키운다 | 혼자서 어디까지 뻗을 수 있는가 |

## 한 줄

> 브랜처는 1인 벤처 스튜디오입니다. 새로운 가지를 뻗고, 사업으로 키웁니다.

## 세 줄

> 모든 사업은 하나의 가지에서 시작된다.
> 브랜처는 분야를 가리지 않고 가지를 뻗고, 빠르게 내놓고, 반응이 오는 것을 사업으로 키우는 1인 벤처 스튜디오입니다.
> 혼자서 어디까지 뻗을 수 있는지, 증명해갑니다.

## 소개 페이지

```
brancher.
모든 사업은 하나의 가지에서 시작된다.

브랜처는 1인 벤처 스튜디오입니다.
분야를 가리지 않고 가지를 뻗고,
빠르게 만들어 시장에 내놓고,
반응이 오는 것을 사업으로 키웁니다.

Branch out. Build ventures.

문의  brancher.lab@gmail.com
```

## 영문

> brancher is a one-person venture studio. Every venture starts with a single branch.
