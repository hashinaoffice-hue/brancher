# 이름 점검 — 1차 (2026.10.26)

웹 검색 기반 1차 점검. 상표 DB·도메인 등록 정보·SNS는 이 작업 환경에서 직접 접속이 막혀 있어 **확정이 아닙니다.** 표시된 항목은 직접 확인이 필요합니다.

## 해석

**1. 한국어 '브랜처'는 깨끗하다.**
국내에서 같은 이름으로 활동하는 회사·브랜드가 검색되지 않았습니다. 국내 활동 기준으로는 좋은 출발점입니다.

**2. 영문 'brancher'는 이미 여러 곳에서 쓰인다.**
- Brancher.ai는 '앱을 만드는 서비스'라 업종이 일부 겹칩니다. 다만 국가(미국)와 형태(SaaS 제품 vs 벤처 스튜디오)가 다릅니다.
- Git 도구들이 `brancher`를 쓴다는 건, 개발자에게 이 단어가 **설명적인 단어**로 느껴진다는 뜻입니다. 브랜드 은유가 잘 통한다는 증거이면서, 영문 단어만으로는 상표 식별력을 인정받기 어려울 수 있다는 신호입니다.

**3. 그래서 상표는 '조합'으로 지킨다.** *(제안 — 최종 판단은 변리사)*
- 영문 단어 단독보다 **`brancher | 브랜처` 병기 + 로고(심볼)** 를 함께 출원하는 편이 식별력 확보에 유리합니다.
- 심볼(줄기 + 45° 가지 + 그린 스퀘어)은 독창적인 도형이라 도형 상표로서 가치가 큽니다.
- 검토할 상품류: 제35류(사업 관리·컨설팅·인큐베이션), 제42류(소프트웨어 개발·SaaS), 제9류(앱), 제36류(투자 — 투자 기능을 할 경우).

**4. 핸들은 '하나로 통일'이 원칙이다.**
`brancher`는 GitHub에서 이미 막혔으므로, 모든 채널에서 같은 핸들을 쓰려면 대안이 필요합니다.

| 후보 | 장점 | 단점 |
|---|---|---|
| `brancher.studio` | 정체성(스튜디오)이 바로 보임 | GitHub은 `.` 불가 → `brancher-studio` |
| `brancher_kr` | 국가가 분명 | 해외 확장 시 어색 |
| `brancherhq` | 짧고 범용 | 'HQ'가 브랜드 톤과 다소 거리 |
| `hi.brancher` | 친근 | 브랜드 보이스(단정함)와 안 맞음 |

→ 제안: **`brancher.studio`** (인스타·스레드) / **`brancher-studio`** (GitHub). 도메인도 `brancher.studio`가 비어 있다면 핸들·도메인이 완전히 일치합니다.
