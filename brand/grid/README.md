# Grid

게시물 레이아웃 가이드. 사용자가 이 위에 가이드(여백·정렬선)를 표시하면, 그것을 기준으로 레이아웃 규칙을 확정한다.

| 파일 | 규격 | 작은 칸 | 큰 칸 | 비고 |
|---|---|---|---|---|
| `grid-1080x1350.svg` / `.png` | 1080 × 1350 (4:5) | 27px (40 × 50칸) | 270px (4 × 5칸) | **인스타그램 표준.** 지금까지의 모든 게시물 규격. 좌우 붉은 띠 = 프로필 그리드 3:4 썸네일에서 잘리는 34px |
| `grid-1000x1350.svg` / `.png` | 1000 × 1350 | 25px (40 × 54칸) | 250px (4 × 5.4칸) | 요청 규격. 4:5보다 세로로 길어 인스타그램 업로드 시 위아래가 잘린다 |

- SVG 레이어(`<g id>`): `background` · `crop-3x4` · `minor-*` · `major-*` · `center` · `frame` · `labels` — 피그마·일러스트레이터에서 레이어별로 켜고 끌 수 있다.
- 붉은 점선 = 가로·세로 중앙.
