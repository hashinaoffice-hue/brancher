## 원본 파일 메모

- 원본 심볼은 의도적으로 캔버스 중앙보다 오른쪽에 놓여 있습니다(시각 보정). 파생 파일을 만들 때는 형태가 아니라 **캔버스 중심**을 기준으로 자르고 확대합니다.
- 원본의 블랙은 색 지정이 없어 순수 `#000000`으로 렌더링됩니다. 브랜드 블랙은 `#0F1110`입니다. 눈으로는 구분이 어렵지만, 다음에 원본을 다시 내보낼 때 `#0F1110`으로 맞추면 좋습니다.
- 워드마크 그린 스퀘어의 모서리 반경은 1.5로, 크기 대비 약 6%라 사실상 각져 보입니다. 심볼 스퀘어는 약 20%입니다. 마침표를 더 또렷하게 보이려는 의도라면 그대로 두고, 아니라면 반경 5 정도로 맞추는 것을 검토하세요.
